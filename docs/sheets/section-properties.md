# 常用截面特性

矩形和常见截面的几何特性计算。

## 矩形截面

| 符号 | 含义 |
|------|------|
| $b$ | 截面宽度 |
| $h$ | 截面高度 |

面积：$A = b \cdot h$

惯性矩：$I_x = \dfrac{b h^3}{12}$

抵抗矩：$W_x = \dfrac{b h^2}{6}$

回转半径：$i_x = \dfrac{h}{\sqrt{12}}$

---

## 圆形截面

面积：$A = \dfrac{\pi d^2}{4}$

惯性矩：$I = \dfrac{\pi d^4}{64}$

---

## 环形截面

面积：$A = \dfrac{\pi (D^2 - d^2)}{4}$

惯性矩：$I = \dfrac{\pi (D^4 - d^4)}{64}$
