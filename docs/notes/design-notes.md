# 设计心得

结构设计中的一些经验总结。

## 板配筋

### 板厚取值

| 板类型 | 最小厚度 | 建议厚度 |
|--------|----------|----------|
| 单向板 | L/30 | 100-120mm |
| 双向板 | L/40 | 100-150mm |
| 悬挑板 | L/12 | 120-150mm |

### 钢筋配置要点

- 底筋常用 φ8@150-200，支座负筋 φ8@100-200
- 大跨度板注意挠度和裂缝验算
- 洞口周边须补强钢筋

### 常见问题

> TSSD 搜板失败 → 检查梁线是否闭合，先用 JX 命令做交线处理
