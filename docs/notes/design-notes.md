# 设计心得

结构设计中的一些经验总结。

## 板配筋

### 板厚取值

| 板类型 | 最小厚度 | 建议厚度 |
|--------|----------|----------|
| 单向板 | L/30 | 100-120mm |
| 双向板 | L/40 | 100-150mm |
| 悬挑板 | L/12 | 120-150mm |

### 钢筋配置要点

- 底筋常用 φ8@150-200，支座负筋 φ8@100-200
- 大跨度板注意挠度和裂缝验算
- 洞口周边须补强钢筋

### 常见问题

> TSSD 搜板失败 → 检查梁线是否闭合，先用 JX 命令做交线处理

## 梁配筋
悬臂梁需设置箍筋加密（eg：阳台两边的悬臂梁）
- 底筋应该直径大的在第一排/前面
- 配筋率超过0.2%，箍筋直径要加大一级
- 拉通钢筋要满足配筋最大值的1/4的要求
    框架梁（一、二级抗震）沿全长贯通的面筋和底筋，其截面面积不应小于**梁两端支座负弯矩钢筋较大值的 1/4**，且不少于 2 根。三级抗震为 1/5（高规 6.3.4）。
    为什么：*地震往复作用下，梁端交替出现正负弯矩。若通长筋太少，跨中可能出现无筋区，导致脆性破坏。通长筋起"兜底"作用。
    我们的做法：面筋用小直径贯通 + 支座大直径附加。贯通筋满足 1/4 的下限即可，支座不够的量用附加短筋补充，避免全长大直径造成浪费。
- 尽量减少钢筋搭接
- 截面标注不要在两条梁线里面
- 标准层钢筋最大直径建议不超过22，框架梁最小14，次梁最小12
- 梁跨度4m以内拉通
- ==纵向构造钢筋截面面积不应小于梁跨中下部纵向受力钢筋计算所需截面面积的1/4，且不少于2根。==
- 架立钢筋（现浇绑扎钢筋？？）架立筋 = 构造需要，不参与受力计算，主要用于**次梁**维持钢筋骨架。框架梁（主梁）应配置通长受力筋，不用架立筋。次梁架立筋：一般采用 Φ10 或 Φ12，与箍筋搭配：箍筋用 Φ6@200（梁高≤600）或 Φ8@200（梁高>600）。（NΦ12） 中的 N 表示根数，这是纯架立筋的做法（即梁上部没有通长受力筋时，用多根架立筋来维持骨架）
- 箍筋：次梁无加密区，但当支座计算配筋较大时，可局部加密（如 Φ6@150/200），[[结构统一技术措施（总）]]第6条
- 支座筋：支座配筋不宜超过计算配筋的 1.1 倍（[[结构统一技术措施（总）]]第2条）
- 通长筋+支座附加的模式：小直径贯通+大直径支座附加（[[结构统一技术措施（总）]]第4条）
- 框架梁在满足计算情况下，第二排底筋不伸入支座

注意：
- 顶底面通长钢筋直径不小于12
- 计入受压钢筋的梁端截面有效区高度≥0.35
- 梁端底面（受压）钢筋 / 顶面（受拉）钢筋截面面积≥0.3
- 箍筋间距加密区不宜大于加密区的2倍
- 纵筋最小净距：梁上部钢筋水平方向的净间距不应小于30mm和1.5d；梁下部钢筋水平方向的净间距不应小于25mm和d。当下部钢筋多于2层时，2层以上钢筋水平方向的中距应比下面2层的中距增大一倍；各层钢筋之间的净间距不应小于25mm和d，d为钢筋的最大直径。
- 框架梁内贯通中柱的每根纵向钢筋直径不宜大于1/20L（L为矩形边长或圆形直径）。
