# 规范阅读笔记

广东省院结构技术措施 & 建筑结构设计实用指南 — 阅读摘录与理解。

---

## 一、周期与扭转

**第一平动周期**：建筑沿某一主方向最主要的振动模式（平动）对应的周期。`TX ≈ TY` 意味着 X 向刚度 ≈ Y 向刚度，结构比较均衡。

| 概念 | 说明 |
|------|------|
| 平动 | 整个建筑沿某个方向整体前后摇动 |
| 扭转 | 建筑围绕垂直轴旋转 |
| 周期短 | 刚度大，振动快 |
| 周期长 | 刚度小，振动慢 |

!!! tip "扭转位移比放松条件"

    当楼层的最大水平位移角 ≤ 规范限值的 **40%** 时，扭转位移比限值可适当放松至 **1.6**。

!!! warning "调整扭转周期比的原则"

    一般应采用**加强周边结构构件**提高结构抗扭刚度的措施，应避免采用**削弱中间部位**剪力墙或核心筒以降低平动刚度的做法。

## 二、抗震设防

### 设防类别

| 类别 | 重要性系数 γ | 适用范围 |
|------|:-----------:|----------|
| **重点设防类** | > 1.0（通常 1.2~1.5） | 医院、消防站、公安局、供水/供电关键设施、学校（尤其小学/幼儿园）、大型公共建筑、重要工业建筑、桥梁、核设施 |
| **标准设防类** | = 1.0 | 住宅、办公楼、一般学校、普通厂房 |

> 重点设防类的设防烈度高于常规值。大型商场 / 结构单元内经常使用人数超过 8000 人的办公室公寓也属于重点设防类。

### 抗震性能设计目标

住宅结构一般按 **C 级**抗震性能目标控制，谨慎选用 D 级。C 级性能目标的结构构件承载力设计要求参考《高规》表 3.11.3。

## 三、嵌固部位

> **3.2.9** 上部结构嵌固部位应按地下室结构的整体性和结构的楼层侧向刚度比来确定。

!!! note "四条要点"

    1. 确定嵌固部位时，楼层侧向刚度比的计算**不考虑土对地下室侧墙的约束作用**。
    2. 地下室顶板作为嵌固端时，相关范围不应采用无梁楼盖。梁截面高度 ≥ 700mm 且板跨 ≤ 4.5m 时，板厚可适当减少，但 ≥ 150mm。
    3. 顶板不作为嵌固端时，需按嵌固部位及地下室顶板**两种情况进行包络设计**，楼板厚度 ≥ 150mm。
    4. 顶板室外区域因覆土降低标高时，高低跨位置梁采取加宽截面、箍筋加大加密等措施，满足侧向刚度比要求时**可不作错层考虑**。

---

## 四、地震剪力调整

楼层地震剪力应满足《抗规》GB50011-2010 第 5.2.5 条的要求。

| 场地类别 | 不满足时的处理 |
|----------|---------------|
| I 类、II 类 | 乘以增大系数调整楼层剪力，**不宜加大结构刚度** |
| III 类、IV 类 | 先调整结构布置增加刚度使剪力系数 ≥ 规范值的 **85%**，再乘以增大系数 |

## 五、结构布置原则

### 竖向构件

- 高层住宅尽量避免竖向构件突出砖墙面，宜采用**双向布置的剪力墙或扁平柱**
- 避免过多的短肢剪力墙及一字形剪力墙
- 尽量使建筑室内空间"**无梁无柱**"

### 转角窗

建筑平面设置转角窗时：
- 加强角部楼板
- 转角窗两侧剪力墙端加设宽扁暗梁，截面一般取 **600×h**（板厚）
- 纵筋直径 ≥ 14mm

### 梁与空间

户内空间主次顺序：**客厅 → 餐厅 → 过道（主卧室）→ 主卧室（过道）→ 次卧室 → 厨厕 → 其他**

- 客厅、餐厅及独立空间尽量不设梁或侧露梁
- 必须侧露梁时，将梁露在相对次要的空间
- 卫生间采用 350mm 沉箱设计，主卧套间卫生间局部沉板处理，避免明梁

### 材料

- 地下室底板、楼板及侧墙混凝土强度等级 **≤ C40**
- 一般楼板配筋宜采用 III 级钢
- 钢筋间距归并：常用 @100、120(125)、150、180(175)、200mm，手工绑扎优先 @100、150、200mm

## 六、荷载作用

### 风荷载

!!! note "4.1.3 基本风压"

    基本风压的重现期与设计使用年限应一致。安全等级为一级或高度 > 60m 的高层建筑：

    - 结构水平位移按 **50 年**重现期的风压值计算
    - 承载力设计时按基本风压的 **1.1 倍**采用

### 消防车荷载折减

| 构件 | 折减系数 |
|------|:------:|
| 单向楼盖次梁 | 0.8 |
| 双向楼盖主、次梁 | 0.8 |
| 单向楼盖主梁（框架梁） | 0.6 |
| 墙、柱 | ≥ 0.6 |
| 基础 | **不考虑** |

## 七、结构计算分析

### 抗震分析方法对比

| | 时程分析法 | 振型分解反应谱法 |
|------|----------|----------|
| 原理 | 直接模拟地震加速度时程 | 基于结构振型 + 反应谱组合 |
| 精度 | 高，能得全程响应曲线 | 近似，只有最大值 |
| 计算量 | 大 | 小 |
| 适用 | 超限及复杂高层 | 一般结构 |

!!! tip "何时必须用时程分析"

    当建筑高度属于规范表 5.2.1 范围，或属于超限及复杂高层建筑结构，应采用弹性时程分析法进行多遇地震下的**补充计算**。

### 转换层与嵌固层

!!! warning "5.4.6 转换层及嵌固层的框架梁建议按非调幅梁输入"

    | 术语 | 含义 |
    |------|------|
    | 转换层 | 结构中承重方式发生明显变化的楼层，梁柱内力可能大幅变化 |
    | 嵌固层 | 局部刚度明显增大的楼层 |
    | 调幅 | 梁按楼层剪力、位移按比例"调节"输入地震力 |
    | 非调幅 | 梁直接按结构分析得到的地震作用计算，不按楼层放大或缩小 |

    **原因：** 刚度突变明显，调幅可能低估上部地震作用；受力复杂，非调幅更接近真实受力。

## 八、风荷载参数速查

| 参数 | 取值 / 说明 |
|------|------------|
| 基本风压 | 查规范，各区域不同 |
| 重现期 | 安全等级一级或高度 > 60m：位移用 50 年，承载力 ×1.1 |
| 结构基本周期 | 用动力计算所得周期经**折减后**填入，按方向分别填入 |
| 风振效应 | 高层结构应考虑；横向风振或扭转风振明显时也应考虑 |
| 地面粗糙度 | 大中城市一般 C 类，大城市密集高层城区 D 类 |

## 九、地基基础

### 基础埋深

!!! note "6.2.3 埋置深度（室外地坪至基础底或承台底）"

    | 基础类型 | 埋深 |
    |----------|------|
    | 天然地基或复合地基 | 1/15 ~ 1/18 H，且 ≥ 3m |
    | 岩石地基 | 不受上述限制 |
    | 桩基 | 1/20 H |

    > H = 建筑物室外地面至主体结构檐口高度

- **6.2.4** 埋置深度一般自室外地面算起
- **6.2.10** 高层与裙房之间如不设沉降缝（防震缝），宜设置后浇带

## 十、计算结果判别

主要看以下指标是否正常：

- 结构自振周期及位移（对高层建筑尤为重要）
- 结构单位面积重度
- 整体结构的剪重比、扭转
- 各构件（梁、柱、剪力墙）的内力及配筋

---

## 十一、板厚与梁截面

### 板厚

转换层或加强层之上下层楼盖，板厚取值较大（往往取 **180、200、250mm** 甚至更大），平面内外刚度足够大，柱网中间再布置次梁已无意义。

### 梁截面

| 类型 | 高跨比 h/L | 宽高比 b/h |
|------|:---------:|:---------:|
| 主梁 | 1/10 ~ 1/18 | 1/2 ~ 1/3 |
| 次梁 | 1/12 ~ 1/20 | 1/2 ~ 1/3 |
| 悬挑梁 | 1/5 ~ 1/8 | 1/2 ~ 1/3 |
| 井字梁 | 1/15 ~ 1/20 | 1/3 ~ 1/4 |

梁截面宽度 ≥ 200mm，高宽比 ≤ 4。
